# Support

This repository is a **ForgeGuard-maintained downstream fork** of
[`vllm-project/vllm-omni`](https://github.com/vllm-project/vllm-omni), and **publishes no build artifacts**. Support is split
accordingly.

## ForgeGuard supports

- ForgeGuard documentation under [`docs/site/`](./docs/site/) and
  [`docs/maintainers/`](./docs/maintainers/).
- The recorded fork base in [`FORK_UPSTREAM_BASE`](./FORK_UPSTREAM_BASE) and the sync process.
- The documentation-validation workflow.

→ [Open a ForgeGuard issue](https://github.com/forgeguard-ai/vllm-omni/issues)

## Upstream supports

- vLLM Omni features, correctness, performance, and model support.
- Installation, configuration, APIs, and CLI behavior.
- **All runnable artifacts.** ForgeGuard publishes no image or package, so anything you install or
  run came from upstream and is supported by upstream.

→ [Open an upstream issue](https://github.com/vllm-project/vllm-omni/issues)
→ [Upstream documentation](https://github.com/vllm-project/vllm-omni)

Reproduce product defects against the official upstream distribution before reporting them upstream.

## What ForgeGuard does not promise

- No service-level agreement or guaranteed response time.
- No distribution, build, or packaging of this software.
- No guarantee that this fork's branch state is suitable to run. Use an upstream release.
- No endorsement or support from the upstream project.

## Security

Do not report suspected vulnerabilities in a public issue. See
[`docs/site/fork/security.md`](./docs/site/fork/security.md).
